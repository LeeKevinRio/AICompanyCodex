# APP 專案工作入口

將本目錄複製為 APP 分支根目錄的 project/，填入實際內容。

1. 先讀 brief.md、status.md、decisions.md、backlog.md、company-version.md。
2. 需求與本輪目標寫入 brief.md；每輪收尾更新 status.md。
3. 重要決策與創辦人回饋保留來源與日期，不將假設記作已確認。
4. 使用 ../templates/acceptance.md 的格式建立 acceptance/round-001.md 等驗收紀錄。
5. 專案指定某員工主責時，在 status.md 記錄，不改公司核心。
6. 不在此保存其他 APP 的記憶或任何密碼、金鑰。
