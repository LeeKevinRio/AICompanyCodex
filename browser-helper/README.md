# WorkApp 一般瀏覽器助手

背景無介面瀏覽器可能被 Cake / Indeed 的安全驗證攔下。此助手使用已安裝的 Chrome / Edge 開啟公開搜尋頁，將卡片交回本機 WorkApp，沿用搜尋、去重、篩選及排程。需要瀏覽器與助手頁保持開啟。

## 安裝與配對

1. 開啟 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，開啟開發人員模式，選「載入未封裝項目」，選本資料夾（內含 manifest.json）。
2. 點助手擴充功能圖示。回到 `http://127.0.0.1:8001/`，展開 Cake／Indeed 瀏覽器助手，按「顯示本次配對碼」。
3. 將配對碼貼入助手頁，按連接，保持此頁開啟。回 WorkApp 勾 Cake／Indeed 並搜尋。

這是本機開發版擴充功能，未上架商店。需使用者自行安裝；不能把尚未安裝的狀態稱為已完成自動接入。

## 範圍與資料

- 只允許 www.cake.me、www.indeed.com、tw.indeed.com 及本機 127.0.0.1:8001。沒有 cookies、history 或 storage 權限。
- 只擷取搜尋結果卡片，排除 script、input、form 等元素；不讀取密碼、Cookie 或私人履歷。不複製其他瀏覽器的登入狀態。
- 每頁最多等待 60 秒，原站要求驗證時由使用者在原站完成；不自動解驗證或重試轟炸。
- 每輪前兩頁，並非全站總數；關鍵字與台灣資格仍由 WorkApp 的原有篩選核對，不能把 Indeed 美國結果視為台灣工作。
- 首頁失敗回報受阻，後頁失敗保留首頁。結果存本機 SQLite；資料不足不宣稱全部讀完。
- 配對碼只在執行中的服務與助手頁記憶體。服務重啟即失效，助手頁關閉需重貼。「停止」會立即通知服務取消等待；直接關頁後最遲 70 秒顯示離線。
- 助手安裝不代表真實端對端驗證通過；需安裝後以站內搜尋核對。
