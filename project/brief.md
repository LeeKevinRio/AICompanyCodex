# APP 需求

- 名稱：雀記 / taiwan-mahjong。
- 使用者：四人台灣麻將牌桌的記帳者。
- 目標：快速記下每把結果，算清四家淨收支與東錢。
- 本輪平台：本機響應式網頁 APP，待創辦人試用。
- 創辦人明確需求：台灣麻將紀錄；開局設定規則；中途可修改；自摸才收東錢，金額開放設定。
- 實作假設：底＋每台×總台數；放槍者付一份，自摸三家各付一份；東錢從自摸贏家扣除，另列公帳。預填底 100、台 20、東錢 10，皆可修改，不代表使用者已確認金額。
- 本輪範圍：四人牌局、底台東錢、逐把記錄、撤銷、保存、結算、備份。
- 排除：自動判牌／算台、莊家連莊自動輪轉、多裝置同步、登入、原生安裝包、正式發布。

## 驗收條件

| 編號 | 情境 | 預期結果 |

| AC-003 | 中途改底台及東錢 | 僅新紀錄採新規則 |
