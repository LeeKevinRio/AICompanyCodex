# WorkApp 需求

- 名稱／分支：WorkApp / `workapp`。
- 來源：創辦人 2026-09-30 對話，從 main 開始新的找工作網頁。
- 核心目標：搜尋全球工作，包含移居海外當地就業，不限台灣可應徵或遠端；預設全球範圍（2026-10-05創辦人澄清）。依關鍵字定期掃描相關開缺，可選薪資、是否遠端等條件。
- 本輪必要：真實職缺來源、關鍵字／地點／遠端／薪資篩選、持久化規則、每 6／12／24 小時掃描、發現去重、來源錯誤狀態與手機適配。
- 排除：通知管道（創辦人明确可延後）、自動投履歷、付費資料來源、多使用者與正式部署。
- 工程假設：第一版為個人使用、後端需持續運行；來源先接 Appier、Canonical 與 Remotive；使用者未指定設計，採搜尋為主的工作介面。

## 驗收條件

| 編號 | 操作 | 可觀察結果 |
|---|---|---|
| AC-001 | 搜尋真實來源，切換台灣／全球、關鍵字／遠端／地點 | 顯示相符職缺、來源、地區限制与原始應徵連結 |
| AC-002 | 選薪資門檻與單位，切換保留未明列薪資 | 相同幣別與週期的職缺區間上限符合門檻；未知薪資依選項保留 |
| AC-003 | 儲存掃描條件 | 建立規則，30 秒內首次掃描，6／12／24 小時下一次排程 |
| AC-004 | 重複掃描與服務重啟 | 重複職缺不增加首次發現；重啟保留規則並補執行已到期工作 |
| AC-005 | 暫停／恢復／刪除與來源錯誤 | 可管理規則；失敗明示且保留資料，不把失敗當無職缺 |
| AC-006 | 桌面、375px 手機與 200% 文字 | 核心操作可用，無水平溢出或瀏覽器例外 |
