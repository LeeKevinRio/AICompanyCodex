# 晴盤需求

- 使用者：希望掌握台股短線趨勢及持股風險的個人使用者。
- 創辦人要求：3–5 天趨勢、庫存設定、產業族群 AI 趨勢、個股技術／基本／消息分析與分數、持股停利停損加碼價位、天氣呈現大盤及庫存健康；UIUX 須有成熟首版；可建議功能增減。
- 本輪假設：台股、3–5 個交易日、手機／桌面 Web APP；非創辦人已确认平台決策。
- 本輪交付：可操作且具有完整視覺的互動原型，非完成的實盤預測系統。
- 視覺：深海軍藍與薄荷綠；市場氣象焦點、證據分數、條件式交易計畫。
- 已實作：總覽、CRUD 庫存、本機持久化、族群篩選、股票搜尋、個股情境。
- 未完成：真實資料服務、AI 推論、回測、機率校準、資料來源引用、通知與跨裝置帳號。
- 不承諾固定準確率，不將研究 prompt 當成模型有效性證據。

## 驗收條件

第三輪增補：官方產業 → App 主族群／細項 → 供應鏈題材；完整金融／營建／醫療細分。提供上市櫃全公司目錄與有來源依據的分類，未知標待確認；允許個人分類覆盖但不覆寫官方產業，不改動現有庫存。

第四輪增補：創辦人要求依优先度實作分析。優先完成官方日線／技術指標、營收與累計財報／重大公告、3／5日透明規則情境、依持股量成本的風險價位。這是可操作的第一版規則分析，不能宣稱完整AI模型、可信勝率或策略優勢已完成。

| 編號 | 操作 | 預期 |
|---|---|---|
| AC01 | 查看總覽 | 天氣、庫存與集中度清楚，示範模式標示可見 |
| AC02 | 庫存新增／編輯／刪除 | 合理輸入儲存，損益更新，空庫存處理 |
| AC03 | 族群篩選 | 記憶體／載板／面板對應股票 |
| AC04 | 個股搜尋或切換 | 分數、證據、價位與失效條件一致 |
| AC05 | 手機／桌面瀏覽 | 主流程可操作且無阻擋內容 |
