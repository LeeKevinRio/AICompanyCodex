# 雀記｜台灣麻將紀錄 APP

第一版為響應式網頁 APP，桌面與手機瀏覽器均可操作。

## 本機執行

需要 Node.js 24 或相容版本，無需安裝套件。

```sh
npm run dev
```

開啟 http://127.0.0.1:4173 。伺服器僅監聽本機，手機不能直接使用此網址連到電腦。

```sh
npm test
```

## 功能

開桌與四位玩家、底台、自摸固定東錢、中途修改規則、胡牌／自摸／流局記錄、撤銷、收支及東錢公帳、牌局封存與逐把回顧、JSON 備份匯出匯入。

資料儲存在瀏覽器 localStorage，不含雲端同步或原生安裝包。UI 字型使用 Google Fonts，可用系統字型回退。東南西北為固定座位，莊家與連莊加台需手動算入總台數。

## 原始碼

- `src/engine.js`：計分、東錢、結算及備份格式檢查。
- `src/app.js`：畫面、互動與本機保存。
- `src/style.css`：桌面與手機樣式。
- `server.mjs`：僅提供指定公開檔案，避免暴露公司或 Git 內容。
- `tests/engine.test.mjs`：計分與資料驗證測試。

公司設定沿用 1.0.0，專案開發不得改寫員工核心。
