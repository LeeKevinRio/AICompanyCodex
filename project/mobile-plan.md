# 手機 APP 準備（2026-09-16）

## 方向
創辦人指定以 iOS 為優先目標，目前持續以網頁測試與驗收。原生技術選型、安裝包與商店發布尚未開始。

## 本輪已做
- 莊家及連莊獨立大字資訊區，座位金框輔助辨識。
- viewport-fit=cover 配合四邊 safe-area，預留瀏海與底部手勢區。
- 手機主要操作至少 44 CSS px，表單文字 16px；彈窗使用動態視窗高度並可捲動。
- 計分維持獨立 src/engine.js，後續介面改造仍以現有測試保護帳務規則。

## 後續階段
1. 網頁完成手機操作驗收：單手操作、直橫向、長姓名、大字、鍵盤遮擋、深淺主題。
2. 原生開發前抽出儲存與備份介面，明確化瀏覽器資料搬移至手機的匯入流程；保留玩家 ID 與規則快照。
3. 評估沿用網頁介面或原生介面，決定後再建立 iOS 工程；目前不引入未使用的框架。
4. 真正 iPhone/Safari 與 iOS 測試環境驗證：安全區、鍵盤、前背景恢復、離線、資料保存與匯出分享。
5. 原生安裝與發布另排工作；簽署、商店與發布由創辦人決策。

## 驗證界線
本輪只做桌面瀏覽器 375/390px 響應式檢查，沒有執行 iPhone、Safari、模擬器或原生測試。資料目前仍在瀏覽器 localStorage，不能宣稱已成為 iOS APP 或具備完整離線能力。
