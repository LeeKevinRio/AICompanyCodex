# 四頁改善建議（待創辦人選擇）

依八位員工職責由同一代理整理，非八位獨立審查；本輪僅實作牌桌東錢金額配色。

| 職責 | 建議 |
|---|---|
| 林知衡／總監 | 優先完成快速續打、記錯可修、結算可核對，再擴充統計。 |
| 許映辰／產品 | 列表進行中置頂、日期分組；提供沿用上桌四人與規則開新桌，需確認才建立。 |
| 沈若晴／設計 | 牌桌突出目前風圈局位、莊家連莊、四家收支；規則與管理收進次要入口，保留大觸控區。 |
| 周以承／技術 | 四頁由同一計算結果產生；曲線可切打牌收支／全部收支，避免額外收付造成曲線與結算難核對。 |
| 陳予安／前端 | 記帳完成顯示短摘要與立即撤銷；紀錄點整列展開詳細資訊，再修正，維持只上下捲動。 |
| 程修遠／資料 | 額外收付也能明確修正或沖回；明細可查當時底台、倍率、東錢、修正前後。以四家淨額加公帳等於零檢查帳務。 |
| 葉見微／測試 | 加入隔離的練習牌局；實測快速連點、防重複、重載、跨日、長姓名、大金額、修正後莊家與帳務。 |
| 何穩舟／維運 | 結算後提供單桌備份與分享摘要預覽；保存失敗須明確提示並保留輸入，避免誤以為已記帳。 |

## 建議順序

1. 立即撤銷、額外收付修正、防重複記帳與保存失敗處理。
2. 牌桌局位層級、紀錄點整列展開，保留列表簡潔。
3. 曲線切換範圍、統計加有效把數；不以少量結果給技術評分。
4. 沿用上桌、練習牌局、單桌備份與分享。

以上均為提案，未取得實作授權，不填為驗收通過。
