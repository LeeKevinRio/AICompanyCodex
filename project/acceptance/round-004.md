# 第四輪驗收

預覽 http://127.0.0.1:4173 。待創辦人驗收。

1. 牌局列表選本局統計，確認只有該桌把數、收支與曲線。
2. 玩家列表進入個人頁，確認跨局總數，並可追溯參與牌局。
3. 新增牌局選擇已有玩家，延續該身分的累計，不變動舊桌數據。
4. 進入牌桌點任一玩家頭像，確認預選本人且放槍者不含本人；切換胡牌者後選項隨之更新。
5. 每桌將數依 16 次換莊為一將；舊資料缺少莊家追蹤時顯示未追蹤。

驗證：22 項單元測試通過；瀏覽器實測預設列表、進桌、點小安預選小安、放槍選項只含其他三人、自摸預覽、玩家列表累計。舊紀錄保持原金額；首次玩家遷移同名視為同人，若舊桌有同名不同人需後續拆分。
