# 第四十二輪：現金流加權與美股頁面（2026-11-01）

狀態：待創辦人驗收；非正式發布。本輪單一主代理依九職責完成，自我檢查不是獨立審查。

## 需求與實作

1. 創辦人要求自由現金流必須參與檢查。新增固定試驗v5：技術80%＋現金流健康20%，65以上偏多、35以下偏空、其餘震盪。現金流健康分由正負狀態與單季變化各占50%；營業現金流負值扣25分、下限0，年度累計FCF為負時最高50。正負狀態正值100、零50、負值0；季變化改善100、不變50、減少0。這是先定義的政策權重，未按歷史結果調優，尚無證據勝過v4。
2. 使用相同CFO−設備支出口徑的單季，累計資料由相鄰完整季度差分；跨年Q1不減去年Q4累計。呈現上季與去年同期、相對前期絕對值的變化百分比，基數0時不硬算。缺前季、資料過舊時暫停綜合預測、保留v4技術參考。負值、轉負、營業現金流下降及資本支出增加顯示原因，不等同必然下跌。ETF仍不適用公司FCF。
3. 官方已知較新季度優先，不因聚合資料較舊而使用舊季評分；2330官方單季由百萬元轉元後與同口徑前季比較，保留各期原始來源。FinMind原公告日仍未知，不把當前財務用於歷史預測。
4. 新v5首次方向及財務證據單獨保存，與舊v4模型／命中率分組。90日重播、成本驗證與歷史類比仍是v4技術，直接標示非v5績效。每日執行對缺財務檢查明示跳過原因，不把技術參考當完整新預測。
5. 新增美股導覽與研究頁：代碼查詢／快捷入口、Yahoo公開美元行情、美東時間、90筆價格線、自選、美元庫存增改刪／復原、小數股、損益及重整保存。美股用獨立瀏覽器儲存鍵，不改台股帳本；原幣分帳，尚未匯率換算合計。
6. 美股後端只接受合法代碼，不接受庫存成本股數；核對USD、美國交易所、商品類型、價格及時間。未知／來源失敗不產生示範行情。只採正常盤參考，不含盤前盤後，來源延遲及可用性無保證。圖中最新當日bar可能未收盤，已標示。
