# 第 2 輪驗收

- 狀態：待創辦人驗收，未提交或發布。
- 預覽：http://127.0.0.1:4173
- Debug：開局畫面按「一鍵填入四位玩家」，會填入四個不同姓名及頭像，保留底台東錢，不自動新增帳務。
- 深色：預設深色；右上角可切換並保存偏好。
- 頭像：開局選擇，牌桌點人像可更換，共 8 款原創 SVG 點陣人像。
- 分析：選單「牌局分析」，可選目前或歷史牌局，查看每把曲線、各人統計及詳細明細。
- 計算：勝率包含胡牌與自摸，自摸率只計自摸；兩者與放槍率的分母均為非流局把數。下家按東→南→西→北→東。平均台數包含自己的胡牌、自摸。分母零顯示「—」。
- 驗證：npm test 15 項通過，新增統計流局處理、下家循環、收支曲線、空資料及頭像相容性。
- UI 實測：一鍵填入與開桌、頭像改紫髮後重載保持、深淺色切換後重載保持、統計與逐把數值一致、390px 手機頁面無水平溢出。
- 限制：資料仍保存在本機瀏覽器；非跨牌局個人長期戰績；比率定義待使用者確認。
