# 晴盤 ClearSignal

台股真實庫存與公開行情版本。行情由本機代理查詢 TWSE MIS，15 秒輪詢，10 秒內相同查詢共用快取；公開端點無延遲、可用性保證。每檔顯示成交時間與盤中／盤後／過期／無成交狀態。已移除合成行情、假圖表、固定分數與價位；AI 分析未完成。

啟動：在儲存庫根目錄執行 `python stockapp/server.py`，開啟 http://127.0.0.1:8765 。必須用此服務，普通靜態伺服器或直接開啟 HTML 不提供行情 API。

真實庫存從空白開始，輸入股票代碼、整數股數、平均成本。支援上市與上櫃代碼查詢，非預設股票依代碼取得名称；族群暫標未分類。搜尋代碼或已收錄名稱後按 Enter。庫存保存在 localStorage 的 clearsignal-holdings-real-v2，舊版示範資料不自動搬入，也不刪除。可匯出 JSON 備份；刪除可在當前頁復原上一次。成本、股數不傳給來源，來源僅收到查詢代碼。

缺價／過期／連線失敗的庫存，不計算總市值與損益；既有快照價格會標示失敗，不能當成新價格。盤中超過 3 分鐘的成交快照標示過期；跨日快照也標過期，週末休市估值規則尚待改善。天氣僅映射加權指數當日漲跌，不是短線預測。族群只統計關注名單。

視覺：海軍藍、薄荷綠、琥珀色氣象；響應式側欄／手機頂部導航。中文字型可選用 Google Fonts，離線使用系統字型。

測試：`node --test stockapp/tests/model.test.js`；`python -m unittest discover -s stockapp/tests -p test_*.py`。

## 三層分類目錄

「族群行情」提供 29 大類、235 細項（醫療 30 項），可依大類、細項、供應鏈題材、名稱／代碼搜尋與分頁。分類快照包含 1,988 家上市／上櫃公司、40 個產業鏈頁面、5,323 筆角色，來自 TWSE／TPEx 公司名冊與櫃買產業價值鏈。僅目前頁面 20 檔、六檔初始關注股或持股依所在頁面查報價，不輪詢全市場。

官方產業用於基礎分類；細項依來源規則與少量已查證公司業務資料整理；不能將供應鏈參與當作營收主業或受惠保證。多角色／來源不足標待確認。個股可「調整我的分類」，選擇所有已建立細項，另存 clearsignal-classification-overrides-v1，可恢復來源分類，完全不改持股 v2 的股數與成本。

所有細項都有選項，但不是所有細項都有已確認的成分公司。ETF 不在公司名冊內，持有或查詢基金後可指定個人商品分類；全市場 ETF 成分目錄尚未建立。

分類快照更新：`python stockapp/build_classifications.py`，此維護腳本需要 BeautifulSoup4（本輪環境已具備）；啟動服務本身只需 Python 標準庫。快照沒有帳戶、成本或持股個資。來源公司業務補充的查證日期寫在 taxonomy.js，不會隨每次行情輪詢自動更新。

完整測試：`node --test stockapp/tests/*.test.js`；Python 測試命令同上。

## 真實分析（第四輪）

開啟「個股分析」或搜尋股票，會取得12個月上市／上櫃官方日線，計算MA5／10／20／60、Wilder RSI14／ATR14、MACD12／26／9、量比、20日支撐壓力與透明技術評分。盤中不使用未完成的當日日線；14:30後才納入當日官方日線。日線來源：TWSE STOCK_DAY、TPEx tradingStock。

基本面顯示最新可得月營收、年增／月增與累計EPS、淨利；明確區分累計財報與單季數字。消息面接TWSE／TPEx最新重大公告快照，保留主旨、發言及事實發生時間、原文與來源。不是完整一週新聞；沒有公告不判為利多。ETF不套用公司財報。金融、營建、新藥公司尚需產業專用財務模型，規則評分不是估值。

3／5交易日情境是透明技術規則v1，尚無校準的AI上漲機率。歷史回顧依當時可得日線順序計算、不重疊取樣，沒有將今天財報灌入過去；對照固定偏多基準。回顧少於30點不顯示命中率；同類情境少於30樣本不估報酬區間。這不是含交易成本的策略回測，也不代表已證實模型優勢。

風險計畫依有效最新成交、ATR、支撐壓力，計算停損／停利／突破加碼觀察價。價位按股票／台幣ETF升降單位取整，區分現價回撤與成本損益。缺價、過期、零波動、價格尺度跳變或交易制度風險不生成計畫。日線未還原，偵測到大跳變、**註記或超過20日資料缺口，僅採用斷點後樣本；不足60筆停用。加碼要符合偏多、價格突破、量比和RSI條件；使用者自行設定最大風險額後才有條件式股數上限，沒有帳戶現金約束與稅費，不能當下單指令。

總覽／庫存自動分析既有持股；族群頁可分析目前頁面最多20檔，再顯示已分析個股的等權技術觀察。庫存加權觀察用持股成本計算，不是安全機率。資料快取30分鐘；初次讀取較久。持股、個人分類與風險預算各自保存，後端只收到代碼／交易市場，不收到股數與成本。

本輪初版：真實來源與規則分析可操作；還原股價、完整新聞、模型校準、產業專用財務模型、交易成本與策略回測仍待完成。介面版本號僅加在靜態檔網址，localStorage來源與鍵保持不變。
